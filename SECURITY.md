# Security policy

## Reporting a vulnerability

Please do not open a public issue for a security problem.

- While this repository is private, report it to the repository owners through a private channel.
- Once the repository is public, use GitHub's **Report a vulnerability** button on the Security tab
  (private vulnerability reporting). The NobleCloak trust center becomes the primary route when it
  is published; its address is added here before the repository goes public.

Include the affected version, a description of the issue, and steps to reproduce it.

## Scope

The plugin in this repository: its commands, hooks and scripts, and the way it stores and sends
credentials and audit events.

## Bug bounty

NobleCloak does not operate a bug bounty program.
